# 苯项链单品展示页：复刻「我的神秘小屋」气质的前端提示词

将以下整段提示词复制给代码助手。目标是做一个只展示“苯项链”这一件作品的前端页面；不创建商品列表、系列页、相关推荐或任何其他商品。

---

## 提示词

请创建一个“苯项链”单品展示网页。页面应高度参考一个名为 **「我的神秘小屋」** 的分子首饰手作店风格：它不是传统轻奢商城，也不是化工产品介绍，而是把有机化学分子结构转译成首饰的创作档案。

重要边界：商品是**苯环造型项链**，是艺术首饰；不销售、不介绍、不鼓励获取或使用化学物质。页面不得出现 SDS、CAS、危险品、化工运输、试剂购买等内容。

只展示一件商品：**苯项链**。不要加入“更多商品”“商品推荐”“系列列表”“搜索商品”“分类筛选”或第二件产品卡片。

### 技术栈

- 使用 React + TypeScript + Next.js（或与此等效的 React 框架）实现。
- 使用 Ant Design 的 `Button`、`Tag`、`InputNumber`、`message/toast` 等基础交互组件；不要套用默认 Ant Design 视觉。
- 使用 GSAP 制作首次入场动画；尊重 `prefers-reduced-motion`。
- 使用 lucide-react 图标。
- 页面必须响应式，桌面、平板、手机均可用。
- 这是前端展示版：可以保留购物袋、数量、登录提示、评论区等界面与交互状态，但无需真实支付、订单、后端请求或登录系统。

### 视觉基调：必须贴近「我的神秘小屋」

不要使用黑白极简奢侈品模板、玻璃拟态、霓虹渐变或红色促销电商风。整体应是有温度的“手作分子首饰档案”。

#### 固定色彩令牌

```css
--ink: #17201c;      /* 深墨绿黑：主标题与正文 */
--cream: #f6f2ea;    /* 奶油纸张底色 */
--paper: #fffdf9;    /* 卡片与浅色纸张 */
--moss: #265842;     /* 苔藓绿：主按钮、重点文字 */
--gold: #c49751;     /* 柔和金色：标签与小强调 */
--muted: #68736d;    /* 低对比辅助文字 */
```

#### 字体与排版

- 中文正文：Arial、PingFang SC、Microsoft YaHei 回退。
- 大标题、章节标题与价格：Georgia、Songti SC 或相近的衬线字，常规字重，不做粗黑标题。
- 大量留白；文字节奏像创作手记，不像成交页。
- 页面底色为 `--cream`，卡片或说明区用 `--paper`；边框使用暖灰米色，阴影极弱。
- 小标题使用全大写英文、宽字距、12px 左右、苔藓绿，例如：`MOLECULE PIECE / 01`。

#### 图像与艺术方向

- 优先使用三类视觉：手绘项链草图、苯环项链主图、近距离材质/佩戴占位图。
- 如果没有真实素材，请用“白底手绘草图纸”“细黑线条苯环吊坠”“奶油纸张与苔藓绿”生成或构造抽象视觉；不要用实验室、烧杯、药片或化工容器。
- 首饰图不是冷峻 3D 渲染，应像独立设计师工作室的设计档案或手作样品。
- 苯环只作为可佩戴的六边形结构语言，线条纤细、轻盈，有留白。

### 页面结构

页面只做一个长页面，所有内容围绕苯项链展开。

#### 1. 顶部导航

- 吸顶高度约 72px，奶油色半透明背景、细米色下边框。
- 左侧品牌：圆形苔藓绿 `M` 标记 + `我的神秘小屋`。
- 中部锚点：`灵感`、`作品细节`、`创作说明`。
- 右侧：`登录`、`注册` 的轻量文本入口，以及购物袋图标、`购物车` 和数量圆点 `0`。
- 手机端隐藏中部导航及登录注册链接，只保留品牌和购物袋；不要留下无功能汉堡按钮。

#### 2. 首屏：单件作品档案

采用桌面双栏布局，最大宽度约 1280px，左右间距宽松。

**左侧文案：**

- 眉题：`MOLECULE JEWELRY / 01`，前置 Sparkles 小图标。
- H1 分三行排版：

  ```text
  把 看不见的
  苯环 戴在
  身上
  ```

  其中“苯环”和“身上”使用苔藓绿色强调。
- 引言：`一枚六边形不是公式的终点，而是佩戴在颈间的一段留白。苯项链从最简洁的环状结构出发，被弯折、连接，并留下一点手作的温度。`
- 主按钮：`查看作品细节`，苔藓绿底、白字，点击平滑滚动至商品详情；带 ArrowRight 图标。

**右侧主视觉：**

- 展示苯项链设计图或产品主图，比例约 640 × 530，使用 `object-fit: cover`。
- 左下角叠加一张白纸质感小注释卡：

  ```text
  手作设计档案
  从结构到首饰
  ```

- 图片不要做浮夸圆角；只使用轻微阴影和纸张边界。

#### 3. 灵感故事区

- 锚点 id：`inspiration`。
- 使用苔藓绿浅色背景 `#e6ece5`，桌面端左右各占一半。
- 左侧是竖幅手绘草图；右侧是文案。
- 眉题：`THE FIRST SKETCH`。
- 标题：`从一个六边形，<br/>到一条项链。`
- 两段文案要有手作与结构转译感，例如：

  `化学式并不冷冰冰。它有闭合、连接和恰到好处的留白。我把最简单的苯环画成草图，再一根根弯折、连接，让它在颈间拥有新的尺度。`

  `这件作品是对分子图谱的视觉致意：不售卖任何化学物质，只分享结构、手艺与好奇心。`

- 底部放金色 Tag：`化学结构艺术饰品`。

#### 4. 商品详情区

- 锚点 id：`details`。
- 页面宽度约 1180px，左图右文，顶部放返回锚点：`← 返回顶部`。
- 左侧图片网格：
  - 主图占满第一行，约 420px 高，展示苯项链。
  - 次图一：`设计参考图`。
  - 次图二：`佩戴图待补充` 的纸张式占位。
- 右侧信息：
  - 眉题：`MOLECULE PIECE / 01`
  - H2：`苯`
  - 副标题：`六边形里的安静光泽`
  - 故事文字：说明作品如何把苯环的封闭结构转为轻盈吊坠。
  - 金色标签：`化学结构艺术饰品`
  - 分隔线后显示 `作品价格` 与 `¥ 699`；价格使用苔藓绿衬线大字。
  - 展示状态：`余 3 件，可加入购物车`；旁边用红褐色小字显示 `仅剩 3 件`。这是界面演示数据。
  - “加入购物车”按钮 + 数量 `InputNumber`。点击后弹出 `已加入购物车 × {数量}` 的成功提示；未登录时提示 `登录后即可加入购物车`。
  - 次操作：`查看购物车`、`返回首页`。
  - 最下方小字：`本作品只将化学结构转译为首饰语言，不涉及任何物质的获取或使用。`

#### 5. 创作说明区

- 锚点 id：`notice`。
- 深苔藓绿实色背景，白色 Atom 图标。
- 标题：`关于这件作品`。
- 说明文字：`苯环在这里是一种视觉结构，而不是化学物质。我们只借用图谱中的线条、连接与留白，完成一件可以佩戴的手作饰品。`
- 不要出现“危险”“运输”“CAS”“SDS”“化工原料”等词。

#### 6. 轻量评论区

- 放在商品详情后，保留“作品留言”形式，而不是大众电商评价墙。
- 标题：`关于这件作品的留言`，旁边显示 `3 条`。
- 可展示 2–3 条静态示例留言，内容围绕设计、佩戴感和送礼；不可显示刷单式“好评”。
- 提供一个静态富文本输入区域与 `发表留言` 按钮；点击后可提示“登录后可留言（演示）”。

#### 7. 页脚

- 浅暖灰背景，居中一行：`我的神秘小屋 · 苯项链 — 以好奇心为线，以结构为形`。

### 交互与动效

- 使用 GSAP 在首屏首次进入时依次执行：
  1. 顶部导航从上方 20px 淡入，约 0.45 秒；
  2. Hero 文字子项从下方 24px 逐个淡入，错峰约 0.08 秒；
  3. 主图以 0.96 → 1 的缩放淡入，约 0.7 秒；
  4. 灵感故事区从下方 26px 淡入。
- 卡片和图片 hover 仅允许极轻的放大（约 1.05）或阴影变化，不要弹跳、旋转、霓虹发光。
- `prefers-reduced-motion: reduce` 时不执行 GSAP 入场或缩放动画。
- 所有按钮、链接、购物袋、数量控件都要有明显的 `focus-visible` 样式。

### 响应式要求

- ≥ 820px：Hero、灵感故事、商品详情都使用双栏；商品详情左右间距约 65px。
- < 820px：导航仅保留品牌和购物袋；Hero、灵感故事、商品详情依次改为单列。Hero 图片高度约 380px；故事图高度约 370px。
- < 500px：页面左右边距 20px；价格、按钮、数量控件不挤压；商品详情的加入购物车区域可纵向排列。
- 不得出现整页横向滚动、文字遮挡、无功能控件或只在 hover 时出现的关键按钮。

### 验收标准

- 页面从头到尾只出现一件商品：**苯项链**。
- 视觉与文案应呈现“我的神秘小屋”的奶油纸张、苔藓绿、手绘草图、分子结构艺术与创作档案感。
- 不应呈现为通用珠宝大促页或化工品说明页。
- 首屏能立刻看清品牌、苯项链、创作概念和查看详情入口。
- 商品详情包含图片、故事、价格、库存演示、数量、加入购物车反馈与创作说明。
- 桌面和手机端均可自然浏览。
- 完成后运行构建命令，确保没有构建错误。
